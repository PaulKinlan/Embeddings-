# Icon Files

This directory should contain the following icon files:

- `icon16.png` - 16x16 pixel icon for the extension toolbar
- `icon32.png` - 32x32 pixel icon for the extension management page  
- `icon48.png` - 48x48 pixel icon for the extension details page
- `icon128.png` - 128x128 pixel icon for the Chrome Web Store

## Creating Icons

You can create these icons using any image editor. The icon should represent the concept of embeddings or AI analysis of web elements. Suggested design elements:

- 🔍 Magnifying glass (analysis)
- 🧠 Brain (AI)  
- 📊 Graph/network (embeddings)
- ⚡ Lightning bolt (processing)

For now, you can use any placeholder images with the correct dimensions, or create simple colored squares as temporary placeholders.

## Temporary Solution

If you don't have icons ready, you can comment out the `icons` section in `manifest.json` and the extension will still work without custom icons.
