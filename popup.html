🔍 Element Embeddings

AI-powered embeddings for every HTML element

Configuration

Usage

Once configured, this extension adds an .embedding property to every HTML element on web pages.

Example Usage:

// Get embedding for any element
const element = document.querySelector('p');
const embedding = await element.embedding;
console.log(embedding);

// Example output:
// {
//   vector: [0.1, -0.2, 0.3, ...], // 768-dimensional vector
//   content: "Element text content",
//   type: "text",
//   timestamp: 1640995200000,
//   model: "text-embedding-004"
// }

Supported Element Types:

  • Text elements: Uses innerText for embedding
  • Images: Uses alt text and src for description
  • Videos: Uses title and src for description
  • Audio: Uses title and src for description
